## Every app speaks a different shortcut language.

Browser tabs, editors, office suites, design tools, and system actions all use their own shortcut rules. The same intention can become a different chord in every app, so the user pays the memory cost, the finger movement cost, and the context-switching cost.

Vimo Rebinder turns those scattered shortcuts into a structured workflow. Instead of asking you to memorize another pile of key combinations, it lets you keep a consistent command layer and adapts the shortcut sent to the app currently in use.

Vimo does not add more shortcuts. It reduces the cost of using them.

## Not Just Another Key Remapper

Traditional key remappers change which key produces which input. Automation and scripting tools expand what the computer can do, often with more power and more setup work.

Vimo sits in a different layer: it reduces the memory, movement, conflict, and context-switching cost of using shortcuts. It overlaps with tools such as AutoHotkey, PowerToys, Karabiner-Elements, and similar utilities in some scenarios, but it is designed to be complementary rather than a full replacement.

## Windows Installation and Privacy

The direct Windows installer is distributed through the official [Vimo Rebinder GitHub Releases](https://github.com/ChenghaoQ/Vimo-Rebinder/releases/latest).

The direct Windows installer uses Vimo's self-signed publisher certificate. Windows may ask you to import the certificate before the first installation. The Microsoft Store version does not require this manual step.

Shortcut configurations are stored locally. Vimo observes keyboard shortcuts and the active application only while its workflow features are enabled.

See the [Privacy Policy](https://app.vimorebinder.com/docs/privacy-policy/), [Windows Installation Guide](docs/windows-installation.md), and [Privacy and Data Notes](docs/privacy-and-data.md) for technical details.

## FAQ

### Is Vimo Rebinder a key remapper?

It can rebind shortcut workflows, but its main purpose is broader: app-specific shortcut structure, visual hints, presets, and a consistent command layer.

### Does it replace AutoHotkey, PowerToys, Karabiner-Elements, or scripting tools?

No. Those tools are excellent for many automation and remapping jobs. Vimo focuses on no-code shortcut workflow management and can be used alongside other tools when their responsibilities do not conflict.

### Does GitHub provide macOS downloads?

No. GitHub release assets publish the Windows installer. macOS users should use the [Mac App Store](https://apps.apple.com/us/app/vimo-rebinder/id6472165219?mt=12).

### Are official Vimo and Microsoft Store purchases interchangeable?

No. They provide equivalent product features, but the purchase records and license restoration paths are managed separately.

### Why does Vimo need keyboard access?

The Super Key, app-specific workflows, floating hints, and rebound shortcut execution depend on keyboard event handling. Disable Vimo when you do not want that behavior active.
