## Cada app fala uma linguagem diferente de atalhos.

As abas do navegador, editores, suítes de escritório, ferramentas de design e ações do sistema usam regras próprias de atalho. A mesma intenção pode virar uma combinação diferente em cada app, então o usuário paga o custo de memória, o custo de movimento e o custo de trocar de contexto.

Vimo Rebinder transforma esses atalhos dispersos em um fluxo de trabalho estruturado. Em vez de pedir que você memorize mais combinações, ele mantém uma camada de comando consistente e adapta o atalho ao app em uso.

Vimo não adiciona mais atalhos. Ele reduz o custo de usá-los.

## Não é apenas mais um remapeador de teclas

Os remapeadores tradicionais mudam qual tecla gera qual entrada. Ferramentas de automação e script ampliam o que o computador pode fazer, mas normalmente exigem mais configuração.

O Vimo trabalha em outra camada: ele reduz o custo de memória, movimento, conflito e troca de contexto ao usar atalhos. Ele se sobrepõe em alguns cenários a ferramentas como AutoHotkey, PowerToys, Karabiner-Elements e similares, mas foi pensado para complementar, não substituir por completo.

## Comece em três passos

1. Instale o Vimo Rebinder.
2. Escolha um fluxo global ou selecione um app.
3. Atribua uma ação a uma estrutura de atalhos que pareça natural.

As dicas flutuantes ajudam enquanto você aprende o layout. Não é preciso usar scripts, e todo atalho pode ser ajustado ou removido.

## Instalação no Windows e privacidade

O instalador direto do Windows é distribuído pelas [Vimo Rebinder GitHub Releases](https://github.com/ChenghaoQ/Vimo-Rebinder/releases/latest) oficiais.

O instalador direto do Windows usa o certificado de publicador autoassinado do Vimo. O Windows pode pedir para importar o certificado antes da primeira instalação. A versão da Microsoft Store não exige essa etapa manual.

As configurações de atalhos são armazenadas localmente. O Vimo observa os atalhos do teclado e o app ativo somente enquanto os recursos de fluxo de trabalho estão habilitados.

Veja a [Privacy Policy](https://app.vimorebinder.com/docs/privacy-policy/), o [Windows Installation Guide](docs/windows-installation.md) e as [Privacy and Data Notes](docs/privacy-and-data.md) para detalhes técnicos.

## FAQ

### O Vimo Rebinder é um remapeador de teclas?

Ele pode reatribuir fluxos de atalhos, mas seu objetivo principal é mais amplo: estrutura de atalhos por app, dicas visuais, presets e uma camada de comando consistente.

### Ele substitui AutoHotkey, PowerToys, Karabiner-Elements ou ferramentas de script?

Não. Essas ferramentas são excelentes para muitas tarefas de automação e remapeamento. O Vimo foca em gerenciamento sem código de fluxos de atalhos e pode ser usado junto com outras ferramentas quando as responsabilidades não entram em conflito.

### O GitHub oferece downloads para macOS?

Não. Os assets do GitHub Releases publicam o instalador do Windows. Usuários de macOS devem usar a [Mac App Store](https://apps.apple.com/us/app/vimo-rebinder/id6472165219?mt=12).

### As compras oficiais do Vimo e as compras na Microsoft Store são intercambiáveis?

Não. Elas oferecem recursos equivalentes, mas os registros de compra e a restauração de licença são gerenciados separadamente.

### Por que o Vimo precisa de acesso ao teclado?

A Super Key, os fluxos por app, as dicas flutuantes e a execução de atalhos reatribuídos dependem do processamento de eventos de teclado. Desative o Vimo quando não quiser esse comportamento ativo.
