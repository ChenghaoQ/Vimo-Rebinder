# Privacy and Data Notes

Vimo Rebinder is a keyboard workflow tool. To provide app-specific shortcuts, floating hints, and shortcut execution, it observes keyboard shortcuts and the active application while its workflow features are enabled.

Shortcut configurations are stored locally on the device.

## Local Data Locations

| Build | Local data location |
| --- | --- |
| Windows installer | `%LOCALAPPDATA%\Vimo Rebinder\Configs` |
| Microsoft Store | Microsoft Store package `LocalState` |
| macOS | App container document/config paths used by the packaged app |

## Analytics

Vimo may use analytics for app-open style product events, including Google Analytics outside mainland China and Baidu Analytics for Simplified Chinese plus Asia/Shanghai environments.

Review the public privacy policy before using Vimo in a managed or sensitive environment:

https://app.vimorebinder.com/docs/privacy-policy/
