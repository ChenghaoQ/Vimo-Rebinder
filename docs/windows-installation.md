# Windows Installation Guide

The direct Windows installer is distributed through the official Vimo Rebinder GitHub Releases page:

https://github.com/ChenghaoQ/Vimo-Rebinder/releases/latest

GitHub Releases publish the Windows installer. macOS distribution is handled through the Mac App Store.

## Installation Options

| Channel | Best for | Notes |
| --- | --- | --- |
| GitHub Releases | Direct Windows installer download | Uses the installer attached to the latest GitHub release. |
| Microsoft Store | Store-managed installation and updates | Store purchase records are separate from official Vimo purchase records. |

## Publisher Certificate

The direct Windows installer uses Vimo's self-signed publisher certificate. Windows may ask you to import the certificate before the first installation. The Microsoft Store version does not require this manual step.

Use the Microsoft Store version if you prefer Store-managed installation and updates without this additional step.

## Troubleshooting

- Download the installer from the latest official release page.
- If Windows blocks the installer, use the Microsoft Store version or follow the certificate prompt shown by Windows.
- For repeatable installation issues, open a GitHub issue and include your Windows version, installer version, and any visible error message.
