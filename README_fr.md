## Chaque application parle une langue différente pour ses raccourcis.

Les onglets de navigateur, les éditeurs, les suites bureautiques, les outils de conception et les actions système ont chacun leurs propres règles de raccourcis. La même intention peut devenir une autre combinaison dans chaque application, ce qui ajoute un coût de mémoire, de mouvement et de changement de contexte.

Vimo Rebinder transforme ces raccourcis éparpillés en un workflow structuré. Au lieu de vous faire mémoriser encore plus de combinaisons, il vous permet de garder une couche de commande cohérente et d’adapter le raccourci à l’application actuellement utilisée.

Vimo n’ajoute pas plus de raccourcis. Il réduit leur coût d’usage.

## Pas juste un autre remappeur de touches

Les remappeurs traditionnels changent la touche qui produit une autre entrée. Les outils d’automatisation et de script élargissent ce que l’ordinateur peut faire, mais au prix d’une configuration souvent plus lourde.

Vimo se place ailleurs : il réduit le coût de mémoire, de mouvement, de conflit et de changement de contexte lié à l’usage des raccourcis. Il recoupe parfois des outils comme AutoHotkey, PowerToys, Karabiner-Elements ou similaires, mais il est conçu pour compléter, pas remplacer entièrement.

## Core System

| Fonctionnalité | Ce que cela signifie concrètement |
| --- | --- |
| Profils spécifiques aux apps | Utiliser le même workflow personnel dans différentes applications, tandis que Vimo envoie le raccourci adapté à l’application active. |
| Super Key | Maintenir ou toucher une touche choisie pour entrer dans la couche de commande de Vimo, puis revenir à la saisie normale à son relâchement. |
| Groupes fonctionnels | Garder ensemble les actions liées, comme les commandes de fenêtre, d’onglet, de bureau, d’édition ou de navigation. |
| Zones de touches spatiales | Placer les actions de fenêtre autour de W, les actions de bureau autour de D, et les commandes voisines près de leur touche de groupe. |
| Indices visuels de raccourcis | Voir les actions suivantes disponibles au lieu de tout mémoriser. |
| Presets et insights | Partir de dispositions préparées et revoir l’usage des raccourcis dans le temps. |

## Commencer en trois étapes

1. Installez Vimo Rebinder.
2. Choisissez un workflow global ou sélectionnez une application.
3. Assignez une action à une structure de raccourcis qui vous semble naturelle.

Les aides flottantes suffisent pendant la découverte de la disposition. Aucun script n’est requis, et chaque raccourci peut être ajusté ou supprimé.

## Installation Windows et confidentialité

L’installeur Windows direct est distribué via les [Vimo Rebinder GitHub Releases](https://github.com/ChenghaoQ/Vimo-Rebinder/releases/latest) officielles.

L’installeur Windows direct utilise le certificat d’éditeur auto-signé de Vimo. Windows peut vous demander d’importer ce certificat avant la première installation. La version Microsoft Store ne nécessite pas cette étape manuelle.

Les configurations de raccourcis sont stockées localement. Vimo observe les raccourcis clavier et l’application active uniquement lorsque les fonctions de workflow sont activées.

Voir la [Privacy Policy](https://app.vimorebinder.com/docs/privacy-policy/), le [Windows Installation Guide](docs/windows-installation.md) et les [Privacy and Data Notes](docs/privacy-and-data.md) pour les détails techniques.

## FAQ

### Vimo Rebinder est-il un remappeur de touches ?

Il peut réaffecter des workflows de raccourcis, mais son objectif principal est plus large : structure de raccourcis spécifique aux apps, indices visuels, presets et couche de commande cohérente.

### Remplace-t-il AutoHotkey, PowerToys, Karabiner-Elements ou les outils de script ?

Non. Ces outils sont excellents pour de nombreuses tâches d’automatisation et de remapping. Vimo se concentre sur la gestion sans code des workflows de raccourcis et peut être utilisé en complément d’autres outils lorsque leurs rôles ne se chevauchent pas.

### GitHub fournit-il des téléchargements macOS ?

Non. Les assets GitHub Releases publient l’installeur Windows. Les utilisateurs macOS doivent utiliser le [Mac App Store](https://apps.apple.com/us/app/vimo-rebinder/id6472165219?mt=12).

### Les achats Vimo officiels et Microsoft Store sont-ils interchangeables ?

Non. Les fonctionnalités sont équivalentes, mais les enregistrements d’achat et la restauration de licence sont gérés séparément.

### Pourquoi Vimo a-t-il besoin d’un accès clavier ?

La Super Key, les workflows spécifiques aux apps, les aides flottantes et l’exécution des raccourcis réaffectés dépendent du traitement des événements clavier. Désactivez Vimo lorsque vous ne souhaitez pas ce comportement.
