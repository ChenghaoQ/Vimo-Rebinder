## Cada app habla un idioma distinto de atajos.

Las pestañas del navegador, los editores, las suites ofimáticas, las herramientas de diseño y las acciones del sistema usan sus propias reglas de atajos. La misma intención puede convertirse en una combinación distinta en cada app, así que el usuario paga el costo de memoria, el costo de movimiento de mano y el costo de cambiar de contexto.

Vimo Rebinder convierte esos atajos dispersos en un flujo de trabajo estructurado. En vez de pedirte que memorices otro montón de combinaciones, te permite mantener una capa de comandos coherente y adaptar el atajo a la app que esté en uso.

Vimo no añade más atajos. Reduce el costo de usarlos.

## No es solo otro remapeador de teclas

Los remapeadores tradicionales cambian qué tecla produce qué entrada. Las herramientas de automatización y scripting amplían lo que puede hacer el ordenador, pero suelen exigir más configuración.

Vimo trabaja en otra capa: reduce el coste de memoria, movimiento, conflicto y cambio de contexto al usar atajos. En algunos casos se solapa con herramientas como AutoHotkey, PowerToys, Karabiner-Elements y similares, pero está pensado para complementar, no para reemplazar por completo.

## Core System

| Capacidad | Qué significa en la práctica |
| --- | --- |
| Perfiles por app | Usa el mismo flujo personal en distintas apps mientras Vimo envía el atajo que corresponde a la app activa. |

| Presets e insights | Empieza con disposiciones preparadas y revisa el uso de atajos con el tiempo. |

## Empieza en tres pasos

1. Instala Vimo Rebinder.
2. Elige un flujo global o selecciona una aplicación.
3. Asigna una acción a una estructura de atajos que te resulte natural.

Las pistas flotantes te bastan mientras aprendes la interfaz. No hacen falta scripts, y cada atajo puede ajustarse o eliminarse.

## Instalación en Windows y privacidad

El instalador directo de Windows se distribuye mediante las [Vimo Rebinder GitHub Releases](https://github.com/ChenghaoQ/Vimo-Rebinder/releases/latest) oficiales.

El instalador directo de Windows usa el certificado de editor autofirmado de Vimo. Windows puede pedirte importar el certificado antes de la primera instalación. La versión de Microsoft Store no necesita ese paso manual.

Las configuraciones de atajos se guardan localmente. Vimo observa los atajos de teclado y la app activa solo mientras las funciones de flujo de trabajo están habilitadas.

Consulta la [Privacy Policy](https://app.vimorebinder.com/docs/privacy-policy/), la [Windows Installation Guide](docs/windows-installation.md) y las [Privacy and Data Notes](docs/privacy-and-data.md) para detalles técnicos.

## FAQ

### ¿Vimo Rebinder es un remapeador de teclas?

Puede reasignar flujos de trabajo de atajos, pero su objetivo principal es más amplio: estructura de atajos por app, pistas visuales, presets y una capa de comandos coherente.

### ¿Reemplaza AutoHotkey, PowerToys, Karabiner-Elements o las herramientas de scripting?

No. Esas herramientas son excelentes para muchas tareas de automatización y remapeo. Vimo se centra en la gestión sin código de flujos de trabajo de atajos y puede usarse junto con otras herramientas cuando sus funciones no se solapan.

### ¿GitHub ofrece descargas para macOS?

No. Los assets de GitHub Releases publican el instalador de Windows. Los usuarios de macOS deben usar la [Mac App Store](https://apps.apple.com/us/app/vimo-rebinder/id6472165219?mt=12).

### ¿Las compras oficiales de Vimo y las de Microsoft Store son intercambiables?

No. Ofrecen funciones equivalentes, pero los registros de compra y la restauración de licencias se gestionan por separado.

### ¿Por qué Vimo necesita acceso al teclado?

La Super Key, los flujos por app, las pistas flotantes y la ejecución de atajos reasignados dependen del manejo de eventos de teclado. Desactiva Vimo cuando no quieras ese comportamiento activo.
