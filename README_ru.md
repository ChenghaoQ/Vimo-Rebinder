## У каждого приложения свой язык шорткатов.

Вкладки браузера, редакторы, офисные пакеты, инструменты для дизайна и системные действия живут по своим правилам шорткатов. Одна и та же задача в каждом приложении может требовать разной комбинации клавиш, а вместе с этим растут нагрузка на память, лишние движения и затраты на переключение контекста.

Vimo Rebinder собирает эти разрозненные шорткаты в структурированный workflow. Вместо того чтобы заставлять вас запоминать ещё одну пачку сочетаний, он сохраняет единый слой команд и подстраивает шорткат под текущее приложение.

Vimo не добавляет новые шорткаты. Он снижает цену их использования.

## Это не просто ещё один remapper клавиш

Обычные remapper'ы меняют, какая клавиша даёт какой ввод. Инструменты автоматизации и скриптинга расширяют возможности компьютера, но обычно требуют больше настройки.

Vimo работает на другом уровне: он снижает нагрузку на память, движения, конфликты и переключение контекста при работе с шорткатами. В некоторых сценариях он пересекается с AutoHotkey, PowerToys, Karabiner-Elements и похожими инструментами, но задуман как дополнение, а не полная замена.

## Как выглядит Vimo в работе

| Workflow | Пример |
| --- | --- |
| Вкладки браузера и редактора | Переключение, закрытие, повторное открытие и перемещение в рамках одной привычной структуры. |
| Управление окнами и рабочими столами | Разместите действия с окнами, переходы между рабочими столами и повторяющиеся действия там, где рука их уже ждёт. |
| Работа в конкретном приложении | Каждому приложению можно задать свои шорткаты, сохраняя привычный Vimo-командный стиль. |

| Super Key | Удерживайте или нажмите выбранную клавишу, чтобы войти в слой команд Vimo, а после отпускания вернуться к обычному вводу. |

| Пресеты и insights | Начинайте с готовых раскладок и со временем анализируйте использование шорткатов. |

## Старт за три шага

1. Установите Vimo Rebinder.
2. Выберите глобальный workflow или конкретное приложение.
3. Назначьте действие структуре шорткатов, которая кажется естественной.

Плавающих подсказок достаточно, пока вы осваиваете раскладку. Скрипты не нужны, и любой шорткат можно изменить или удалить.

## Установка на Windows и конфиденциальность

Прямой установщик для Windows распространяется через официальный [Vimo Rebinder GitHub Releases](https://github.com/ChenghaoQ/Vimo-Rebinder/releases/latest).

Прямой установщик для Windows использует самоподписанный сертификат издателя Vimo. Windows может попросить импортировать сертификат перед первой установкой. Версия из Microsoft Store не требует этого шага вручную.

Настройки шорткатов хранятся локально. Vimo отслеживает клавиатурные шорткаты и активное приложение только пока включены функции workflow.

См. [Privacy Policy](https://app.vimorebinder.com/docs/privacy-policy/), [Windows Installation Guide](docs/windows-installation.md) и [Privacy and Data Notes](docs/privacy-and-data.md) для технических деталей.

## FAQ

### Vimo Rebinder — это remapper клавиш?

Он умеет переназначать workflow шорткатов, но его главная цель шире: структура шорткатов для конкретных приложений, визуальные подсказки, пресеты и единый слой команд.

### Он заменяет AutoHotkey, PowerToys, Karabiner-Elements или скриптовые инструменты?

Нет. Эти инструменты отлично подходят для многих задач автоматизации и remap'а. Vimo сосредоточен на управлении workflow шорткатов без кода и может использоваться вместе с другими инструментами, если их задачи не конфликтуют.

### GitHub даёт загрузки для macOS?

Нет. GitHub Release assets публикуют только установщик Windows. Пользователям macOS следует использовать [Mac App Store](https://apps.apple.com/us/app/vimo-rebinder/id6472165219?mt=12).

### Совместимы ли официальные покупки Vimo и покупки через Microsoft Store?

Нет. Функции одинаковы, но записи о покупке и восстановление лицензии управляются отдельно.

### Зачем Vimo нужен доступ к клавиатуре?

Super Key, app-specific workflow, плавающие подсказки и выполнение переназначенных шорткатов зависят от обработки событий клавиатуры. Отключайте Vimo, когда это поведение не нужно.
